# CyberWorld / Signal Noir art pass

Created for the October 27, 2026 visual update using the built-in `image_gen`
tool. This is original game key art, not a screenshot of runtime graphics. It
appears on the title's cinematic plate and on two actual 3D city billboards.
The playable world, actors, markers and movement remain rendered in WebGL.

Project asset: `CyberWorld/assets/cyberworld/cyberworld-keyart.webp`.
Runtime copy: `play-cyberworld/assets/cyberworld/cyberworld-keyart.webp`.
The selected output was packaged as a 1600 × 900 WebP, 300,764 bytes. The original
generated PNG remains preserved in the local generated-images collection.

The neon city pass adds original holographic signs, data arches, server banks,
rooftop circuitry, an abstract cipher-eye tower and a wet, textured street
surface. A small generated lighting environment supplies cool and magenta
reflections. Reduced-motion settings suppress optional movement.

FBI/CIA labels are thematic references inside the independent training game,
not official branding or endorsement. Illuminate is a fictional crew. Optional
Equation and ShinyHunters dossiers cite [MITRE](https://attack.mitre.org/groups/G0020/)
and the [FBI / IC3 advisory](https://www.ic3.gov/PSA/2026/PSA260515).
No real agency attribution is invented for Equation, and real group names are
not attributed to the fictional Black Freight attackers.
