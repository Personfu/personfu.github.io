Restoration note

What happened to the old documentation?

The documentation was not conceptually gone. The live route at personfu.github.io/GovINT/ was being served from the separate Personfu/personfu.github.io Pages repository. That route only had a generic fallback card, while the deeper GovINT repository still held content such as Arizona history, border history, Fort Huachuca, Davis-Monthan, Palo Verde, water politics, UAP/anomaly files, methodology, documents, and source-reliability material.

This vault rebuilds the public documentation surface directly under the live route so visitors can browse dossiers again instead of landing on a route alias.

Documentation model

  • Start with a claim, rumor, historical event, agency name, facility, contract, or public official statement.
  • Map the source chain: official record, archive, hearing, procurement notice, budget, court file, GIS layer, news archive, or FOIA response.
  • Apply reliability labels: verified, official, confirmed, credible, probable, possible, speculative, disputed, folklore, unresolved.
  • Write the dossier as a public-source narrative with source links and boundaries.
