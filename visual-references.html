Acquisition Rules

No mystery sprites. No unsourced Pinterest dumps. No random hotlinks. Import only generated in-house work, public-domain/CC0 packs, or assets with a license file preserved in the repo. NASA visuals are reference-safe for the Mars atmosphere, but avoid implying NASA endorsement.
