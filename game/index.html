The Grid is reporting quiet anomalies across five districts. You are not dropped into combat cold anymore: build an operative, read the tutorial, understand the combat loop, then enter Mainframe Core.

Storyline

Act I begins in Mainframe Core after an impossible route appears in the academy logs. Ada Root believes it is a training artifact. Chief Vale thinks it is a probe. Cipher Nox claims it is evidence that AXIOM is learning from every route check, cache miss, and discarded token. Your job is to turn noise into evidence.

Tutorial loop

Move and talk

Use WASD/arrow keys. Press SPACE near NPCs, terminals, and objects.

Recon before combat

In combat, RECON reveals the daemon weakness. EXPLOIT without recon is faster but less efficient.

Manage noise

Actions raise threat noise. Too much noise wakes sentinels. Patch, run, or finish cleanly.

Document the lesson

Every daemon is a defensive concept. The reward is not just XP; it is knowing how to explain the failure.

Combat roles

Recon reveals weakness. Exploit deals damage. Patch restores HP. Run exits danger. Item uses inventory. The game is turn-based so you can think like an operator, not panic like a script.
