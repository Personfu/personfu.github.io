JWT Algorithm Confusion: HS256 vs RS256
METHODOLOGY // T-05 // FLAG F31–F33
When a server accepts both HMAC and RSA-signed tokens, an attacker can re-sign a forged token with the public key using HS256, bypassing RS256 verification. Detection: enforce algorithm allowlist server-side. Never trust the alg header from the client.
Zero-Width Space Steganography in Text Documents
FORENSICS // T-03 // FLAG F18
ZWSP (U+200B) and similar invisible Unicode characters can encode hidden binary data in plain text. Detection: paste suspicious text into a hex viewer or use /\u200b/g regex. Remove with str.replace(/[\u200b-\u200d\ufeff]/g,'').
Client-Side Auth Bypass (CWE-602)
CLIENT-AUDIT // T-01 // FLAG F01–F05
Logic gated only in the browser (JS conditionals, hidden form fields, localStorage flags) is trivially bypassed via DevTools. All authorisation decisions must be enforced server-side. Frontend checks are UX only.
