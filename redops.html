▶ DEFENSIVE PAIRINGSyou must teach the blue too

SQLi → Parameterized queries

Use prepared statements + ORM with bind variables. Never concatenate. WAF as defense-in-depth, not primary.

JWT → Pin alg + verify aud/iss

Allow-list a single algorithm in code. Reject "none". Verify audience & issuer claims.

SSRF → IMDSv2 + egress allow-list

Force IMDSv2 (session-token); deny outbound from app subnet by default; resolver allow-list.

XXE → disable DTD/external entities

libxml: LIBXML_NONET + disable DOCTYPE. Java: setFeature("disallow-doctype-decl",true).

Deserialization → typed schemas

Never deserialize untrusted bytes with native pickle/Java/.NET binary. Use signed JSON / protobuf with allow-listed types.

Kerberoast → strong service pw + LDAP gMSA

30-char service passwords, gMSA where possible, monitor 4769 logon events with RC4 ticket flag.
