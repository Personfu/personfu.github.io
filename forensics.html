▶ DOCTRINEblue-team principles

ORDER OF VOLATILITY

Always triage in this order: registers → cache → RAM → network state → disk → archives. Memory dies first; capture it first.

WRITE-BLOCK EVERYTHING

Every disk image is captured under a hardware or software write-blocker. Hash-before, hash-after, document chain of custody.

TIMELINE FIRST, NARRATIVE SECOND

Build a super-timeline before forming a story. Plaso/log2timeline. Anomalies pop on time-clusters.

ASSUME COMPROMISE TOOLING

If the host is compromised, its built-in commands lie. Use signed offline binaries from a known-good kit (KAPE, GRR, Velociraptor).

HASH AND SIGN ARTIFACTS

SHA-256 every artifact at collection. Sign at handoff. Verify at every transfer. Court-defensible chain of custody.

NEVER RUN MALWARE LIVE

Detonate only in an air-gapped sandbox you do not depend on. Snapshot first; revert always.
