Math primitives in this page

The console replays:

  • SHA-256 over the live seal.png bytes (asset binding).
  • CRC-32 (IEEE 802.3 reflected) over the 79-byte alpha-LSB payload.
  • HMAC-SHA-256 verification of the canonical manifest body.
  • Independent Hashcash stamp re-validation (SHA-256(stamp) ≫ 256-bits).

Birthday bound: 𝔼[counter] ≈ 2¹⁸ = 262144 hashes for 18-bit difficulty.

Ten-finding rubric — self-check (local only)

For each finding, type the canonical token from CHALLENGE.md §B. The page hashes it locally with SHA-256 and shows whether the first 4 bytes match the manifest's published commitment. When all ten match, the XOR of the prefixes equals the published master_xor. No network traffic is generated.
