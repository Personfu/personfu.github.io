F18 Incident-response action PENDING

You've identified the supply-chain compromise root cause, rotated all secrets that were exposed in CI logs since 2025-03-14, and pinned the offending GitHub Action to a full commit SHA across all repos. Which classic incident-response action best describes removing the root cause from the environment?

Contain the incident -> remove its cause -> restore and monitor
Framework nuance

The old SP 800-61 Rev.2 lifecycle grouped containment, eradication, and recovery. Rev.3 is a CSF 2.0 community profile; it does not use the five-step list as separate phases. The answer here is an action, not a Rev.3 phase.

F20 Zero-width-space steganography PENDING

The brief above contains an invisible payload between two of its words. Zero-width space (U+200B) encodes binary 0; zero-width joiner (U+200D) encodes binary 1; eight characters per ASCII byte, MSB first.

Look between “Phoenix” and “Operations” in the brief. Keep only U+200B and U+200D, map them to bits, group eight bits into a byte, then decode the bytes as text. The local tool below can demonstrate the extraction; it will not submit the answer for you.
