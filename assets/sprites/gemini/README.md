# CyberWorld Gemini Sprite Sheets

Drop the three generated PNG sprite sheets here using these exact filenames:

- `items-tools-entities.png` — consumables, tools, loot, artifacts, drones, automata, and non-human entities.
- `operatives-hardware-threats.png` — player operatives, vanity customization, gear, hardware, adversaries, and cyber-threat sprites.
- `vehicles-transit-mobility.png` — vehicles, transit kiosks, orbital shuttles, and network mobility systems.

The live atlas page at `/sprite-atlas.html` looks for these paths:

- `/assets/sprites/gemini/items-tools-entities.png`
- `/assets/sprites/gemini/operatives-hardware-threats.png`
- `/assets/sprites/gemini/vehicles-transit-mobility.png`

Until the binary PNGs are committed, `/sprite-atlas.html` supports local browser import and stores previews in localStorage.
