# Animated operative model — Quaternius

`Character.glb` is the animated character from Quaternius's **Cyberpunk Game Kit**.
The model and its animations were made by Quaternius; CyberWorld's environment,
gameplay, character names, palette application and narrative are separate work.
Quaternius is not affiliated with or endorsing CyberWorld.

- Artist/pack: https://quaternius.com/packs/cyberpunkgamekit.html
- Original release (2022-07-11): https://www.patreon.com/quaternius/posts/cyberpunk-game-68965667
- Pack-specific license, verified 2026-10-18: **CC0 1.0**,
  https://creativecommons.org/publicdomain/zero/1.0/
- General current artist license: https://quaternius.com/license.html
  (QAL v1.0, 2026-08-28). It also permits incorporation and distribution in
  finished games. This game does not distribute a standalone asset pack.

The source glTF was obtained in the CyberWorld deployment repository on
2026-10-01, documented by that repository's `ASSET_SOURCES.md`:
Google Drive file ID `1s_mUK4qNGhjNERlXb0gb65QPBedmGBF1`.
Its embedded buffer was repackaged as GLB by `scripts/pack-embedded-gltf.mjs`
without changing the model data. The GLB is self-contained and has no textures
or external network dependencies. CyberWorld changes palette and scale at
runtime; the unused sword attachment is hidden.

The shipped game uses the authored Idle_Neutral, Walk and Run animation clips.
Interact and Wave are retained in the model for future contextual animation.
No model geometry is generated by the procedural fallback when the asset loads.
